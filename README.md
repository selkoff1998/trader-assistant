# Trader Assistant

Помощник трейдера для телефона и компьютера.

- Часы NYSE, LSE, Xetra, Шанхай, Токио, MOEX и крипты: открыто / закроется через / откроется через
- График TradingView
- Избранное, акции РФ, товарка, крипта, поиск по тикеру и названию
- Тепловая карта по сохранённому дневному изменению
- Уведомление за 15 минут и за минуту до открытия или закрытия биржи

## Как открыть

Откройте [index.html](index.html) в Chrome или Safari. Интернет нужен только для графика.

На телефон:

1. iPhone — Safari → Поделиться → На экран «Домой»
2. Android — меню Chrome → Установить приложение или Добавить на главный экран

Избранное и тема хранятся в этом браузере.
